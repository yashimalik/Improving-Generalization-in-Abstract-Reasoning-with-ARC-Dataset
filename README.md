# Improving Generalization in Abstract Reasoning with the ARC Dataset

Faculty-reviewed research paper, BITS Pilani.

## Overview

The [Abstraction and Reasoning Corpus (ARC)](https://github.com/fchollet/ARC) is a benchmark of grid-based puzzles that test an AI system's ability to infer abstract rules such as spatial transformations, color manipulations, and logical patterns. Each task provides only a handful of input-output examples, which makes generalization difficult for standard machine learning models.

This project explores whether data augmentation tailored to ARC's grid structure can help task-specific CNNs generalize better from so few examples.

## Approach

**Data augmentation.** New training pairs are generated by permuting colors within the grids, remapping values, and shuffling. These transformations change how a grid is represented while preserving the structure of the task.

**Preprocessing pipeline.** A custom PyTorch DataLoader handles the varying grid dimensions across ARC tasks, applies random augmentations to input and output matrices, and returns input-output pairs along with their dimension metadata.

**Model.** A separate CNN is trained for each task:

- Conv2D (3 → 50 channels, 3×3 kernel) + ReLU
- Conv2D (50 → 100 channels, 3×3 kernel) + ReLU
- Max pooling + dense layer
- Softmax output

**Training.** Adam optimizer with mean squared error (MSE) loss.

## Key Findings

- Training loss decreased consistently across epochs, showing that the task-specific CNNs learned the input-output patterns in each task's training pairs.
- The analysis identifies three factors that shape how well CNN-based approaches generalize on ARC: the depth of abstract reasoning each task requires, the diversity that augmentation can introduce, and the small number of examples available per task.
- These insights motivate the future directions below.

## Future Directions

- Attention-based or reasoning-driven architectures
- Augmentation strategies that better match the semantic structure of ARC tasks
- Hybrid approaches that combine learned features with rule-based reasoning
